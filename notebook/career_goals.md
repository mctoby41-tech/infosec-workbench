# Career Roadmap: Security Operations Center (SOC) Analyst 

## Primary Target 
* **Target Role:** Tier 1 SOC Analyst / Incident Response Specialist 
* **Target Region:** Pittsburgh Tri-State Corridor 
* **Core Focus:** Triage, log analysis, threat detection, and incident containment workflows 

---

## Core Comptency Pillars

### 1. Fundamentals & Certifications 
- [] Complete CompTia Security+ (SY0-701) exam preparation
- [] Master core security concepts: Network Protocols (TCP/IP, DNS, HTTP/S), threat actors, attack vectors, and controls 
- [] Understand key compliance frameworks (NIST CSF, MITRE ATT&CK)

### 2. Practical Security & Incident Responce 
- [] Complete the SOC Tier 1 Learning Path on LetsDefend.io
- [] Complete the SOC Level 1 Path on TryHackMe
- [] Develop proficiency in log analysis using SIEM tools (Splunk, Elastic)
- [] Conduct packet capture anaylsis using Wireshark and 'tcpdump' 

### .3 System, Scripting & Hardware 
- [] **Linux/Bash:** Command-line text processing ('grep' 'awk', 'sed'), system monitoring, and automated log parsing
- [] **Python:** Custom script development for log extraction, API interaction, and artifact analysis 
- [] **Hardware & Field Auditing:** Utilize embedded hardware (ESP32/M5Stack platforms) and Linux distributions for hands-on network assessment and lab security research

---

## Portfolio & Networking Milestones 

* **Github Portfolio ('infosec-workbench'):**
* Maintain Documented lab writeups for every incident triage excercise. 
* Build reuseable CLI cheatsheets & Python automation scripts. 
* **Community Engagement:** 
* Attend local industry meetups (BSidesPGH, Hackers Guild PGH).
* Build a professional presence on LinkedIn highlighting lab progress and completed writeups. 

---

## Long-Term Vision 
Establish a strong foundation in threat analysis, incident response, and SOC operations to serve as a launchpad into advanced domains, including Machine Learning for threat intelligencem GIS-Integrated analytics, and DevSecOps engineering.
