# Pwnagotchi Wireless Threat Analysis (Retro Documentation)

## Overview
A Pwnagotchi device built to study WiFi handshake capture, rogue AP behavior, and defensive strategies against automated wireless attacks.

## Original Goal
Understand how automated WiFi attack tools operate and how organizations can detect and mitigate them.

## What the Device Does
* Captures WPA/WPA2 handshakes
* Performs automated reconnaissance
* Learns optimal attack timing
* Interacts with nearby networks

## Architecture / Setup
* Raspberry Pi Zero / Pi 4
* Pwnagotchi firmware
* Display module (if used)
* Wireless adapter

## Steps Taken
1. Built and configured the device
2. Tested handshake capture
3. Analyzed captured data
4. Studied attack patterns
5. Documented defensive strategies

## Security Impact
Explain what threats Pwnagotchi simulates:
* Automated handshake harvesting
* Rogue AP interactions
* Passive reconnaissance
* Credential cracking workflows

## Defensive Recommendations
* WPA3 adoption
* 802.11w / MFP
* Network monitoring for rogue devices
* Strong password policies
* Wireless IDS/IPS
