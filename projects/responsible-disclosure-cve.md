# Responsible Vulnerability Disclosure

## Objective
Find a real vulnerability, document it, and perform responsible disclosure.

## Target
* IoT device
* Small web app
* Exposed service

## Tasks
1. Identify vulnerability.
2. Document reproduction steps.
3. Contact vendor.
4. Follow disclosure process.

## Report
* Description
* Impact
* Steps to reproduce
* Mitigation
