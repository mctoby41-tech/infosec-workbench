# Cloud Misconfiguration Lab

## Objective
Simulate common cloud misconfigurations and document how they occur and how to fix them.

## Environment
* AWS / Azure / GCP
* IAM roles
* Storage buckets
* Network security groups

## Tasks
1. Create intentional misconfigurations.
2. Document how they expose data or access.
3. Fix each misconfiguration.
4. Validate the fix.

## Findings
Describe each misconfiguration and its impact.
