PROJECT-ROADMAP.md
A structured progression of cybersecurity projects designed to build real, employable skills.

Phase 1 — Foundations (Easy / High Value)
Build core skills that every security role expects.

1. Network Traffic Analysis (PCAP Hunting)
Learn how to identify malicious traffic, beaconing, and indicators inside PCAPs.

2. Incident Response Playbook + Tabletop
Write an IR playbook and run a tabletop exercise to test your response process.

3. GRC Gap Assessment (NIST / ISO)
Perform a gap assessment and build a risk register for a fake company.

4. Cloud Misconfiguration Lab
Simulate common cloud mistakes and document how they lead to breaches.

Phase 2 — Identity & Cloud Security (Medium Difficulty)
Identity is the new perimeter. These projects build modern defensive and offensive skills.

5. Least Privilege IAM Design
Design a full permission model for a sample app and justify each access decision.

6. OAuth Consent Phishing Demo (Entra ID)
Build a malicious OAuth app, simulate consent phishing, detect it, and harden the tenant.

7. Active Directory Attack & Defend Lab
Build a small AD environment, attack it (Kerberoasting, hash extraction), then detect and defend.

Phase 3 — Automation & Engineering (Medium–Hard)
Show that you can automate, engineer, and scale security work.

8. SOAR Automation Playbook
Automate alert enrichment, containment, ticket creation, or user lockdown.

9. Build Your Own Vulnerability Scanner
Create a basic scanner with port discovery, service detection, and CVE mapping.

Phase 4 — Advanced / Portfolio Showpieces
These projects make your GitHub stand out and give you elite interview talking points.

10. Responsible Disclosure (CVE)
Find a real vulnerability, document it, and perform responsible disclosure.

11. Purple Team Attack Chain Simulation
Combine cloud, identity, and AD attacks into a full attack chain with detection + defense.

12. Cloud + Identity Breach Scenario
Simulate a modern cloud identity breach path and document the entire kill chain.
